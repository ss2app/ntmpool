快速开始（一条命令）

  1. 下载 上面对应平台的 NTMminer
  2. 运行，把地址换成你自己的： 
    NTMminer-brc-cpu-win64-v1.6.0.exe --address <你的64hex地址>
    Linux：./NTMminer-brc-cpu-linux-x64-v1.6.0 --address <你的64hex地址>
    就这一条，别的都不用填。池地址、线程数、绑核、大页全部内置或自动校准：首次启动会自动测算最优线程数与绑核方式（约 20-40 秒，只跑一次，结果缓存，之后秒启动）。
  3. 查收益：回到本页顶部「矿工查询」输入你的地址

接第三方矿池

NTMminer 不锁池。任何兼容 BrowserCoin 池协议（/register + /job + /share）的矿池都能连：
NTMminer-brc-cpu-win64-v1.6.0.exe --address <你在那个池的地址> --pool https://<第三方池地址>
注意：一旦显式写了 --pool，锄头就完全按你指定的来，不会再自动回退到我们的池。地址要填你在那个池登记的收款地址。

全部参数

--address <64hex>
必填。你的 BRC 收款地址（64 位十六进制）
--pool <url>
矿池地址。支持 https:// 与 stratum+tcp://主机:端口。不填则用内置默认池
--threads <n>
手动指定线程数。填了就跳过自动校准
--smt / --no-smt
强制用全部逻辑核 / 只用物理核。每核 L2 小于 1MiB 的平台，用物理核往往更快
--tune
强制重新自动校准并覆盖缓存。换硬件、超频、或觉得算力不对时跑一次
--no-tune
关闭自动校准，用静态默认值
--pin / --no-pin
强制开启 / 关闭线程绑核（默认按 NUMA 分布自动决定）
--interleave <1|2|4>
单线程内交错实例数，默认 1。绝大多数机器保持默认最快
--no-huge
关闭 2MiB 大页（默认开启；大页通常带来明显提速）
--gpu
GPU 模式（仅 GPU 版二进制）。此模式只用显卡，不启动 CPU 线程
--gpu-device <n>
指定第几张显卡，从 0 开始
CPU + GPU 同时挖：开两个进程即可 —— 一个不带 --gpu（跑 CPU），一个带 --gpu（跑显卡），两个都用同一个地址。
EPYC / 线程撕裂者 / 多路服务器等大核机器，建议首次跑一次 --tune，让锄头自己找最优配置。

关于 1% 抽水（明码标价）

NTMminer 收取 1% 抽水：每 100 分钟里有 1 分钟为开发者地址挖矿，其余 99 分钟全部归你。
抽水地址
2520e8d6d0ecb52bf5ba79b3d41a045f6d2aef26984c152f3c19f1d74d7ebab0
怎么核对
锄头启动时会打印这个地址；运行中状态行里的 抽水accepted 就是抽水份额数，和你自己的 accepted 分开计数，随时能自己算比例
时间从哪算
从开始挖矿起算。启动自检与自动校准的耗时不计入，不占你的时间
重启不会多抽
锄头在本机记账，反复重启也不会重复抽首轮 —— 长期严格收敛到 1%
挖第三方池同样是 1%
抽水用的是你所连的那个池，规则一致，不会因为换池而变多
本池池费 5% 与这 1% 是两回事：池费从爆块奖励里收，抽水是锄头的算力时间。两者都写在明面上。
